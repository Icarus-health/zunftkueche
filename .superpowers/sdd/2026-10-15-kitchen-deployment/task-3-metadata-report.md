## Local change and resolved capacity decision

Added drift diagnostics to ResourceEngine.EnsureAsync: a mismatch records the already source-defined resource name, existing fixed error code and an allowlisted field path, e.g. `$.MaxLength` or `$.RequiredLevel.Value`. The allowlist prevents arbitrary property names from becoming diagnostic text; unknown expected keys become `field`, and array paths use `[]`. Remote values, expected payload values, tokens, provider body text and seed/package content are never emitted. RequireMatch retains exact leaf equality, required-field checks and exact array lengths/order. Existing extra managed-property fields remain accepted as before. No write, overwrite, retry, publishing or drift-tolerance capability was added.

**Resolved after Root's read-only session 93634 and explicit ruling.** Once the user completed the DuckDuckGo login, Root's official RetrieveEntity calls both returned zk_name MaxLength 850: RetrieveAsIfPublished=false and RetrieveAsIfPublished=true. EntityDefinitions also returned 850, with all other compared fields exact. This rules out a published-versus-unpublished length discrepancy in the observed readbacks. The reason the create request's 200 became 850 remains undocumented; the implementation makes no universal platform-normalization claim.

Root explicitly authorized changing only the two internal zk_name capacities from 200 to **exactly 850** in the pinned registration contract. That local contract change is now implemented, with SHA256 pin **08bd35ddbb43f12ee2c80eed9048630bebf25a899d012a327db3aa9f647baf47** (previous 46e7fe2b0a71763318bd713df028c3e57ed7d8a7fae380566622a44f94017207). The workspace label matches the observed environment; the not-yet-created operation table will request the same explicitly reviewed internal-label capacity. No existing live column is modified. The generic matcher still requires exact values, so 200, 849 and 851 are rejected. Business state text limits, zk_state capacity, operation ID/hash/actor limits, source/domain/plugin/package code, six guards and ten runtime gates remain unchanged. This is an environment-specific internal label contract choice, not broader business-data tolerance.
