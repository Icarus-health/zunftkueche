Offline OCR assets for the Zunftküche application.
tesseract.js 6.0.1 (Apache-2.0), prebuilt ESM and worker from the npm package.
tesseract.js-core 6.1.2 from tesseract.js 6.0.1 dependency (Apache-2.0), universal LSTM core.
German language model: Tesseract tessdata_fast 4.1.0, distributed by Homebrew tesseract-lang, Apache-2.0. The model is gzip-compressed in deu.traineddata.bin.
The browser reads the invoice locally; worker, engine, and language assets are served by the same SharePoint solution. Do not use default third-party CDN URLs. Model caching is disabled.
